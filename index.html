Data sources & important notes

Cryptocurrency quotes and chart history: public CoinGecko API (subject to rate limits). Precious metals and copper/aluminium reference quotes: Metals.Dev (requires a free or paid API key depending on plan). Enter your key below; it is stored only in this browser's local storage, and is sent directly to Metals.Dev. For greater security on a public deployment, use a server-side proxy instead of a browser key. Steel and brass require a specified grade and a suitable pricing source and therefore display “Not available” rather than made-up numbers. No price is guaranteed to be real-time or executable. All quotes carry a refresh timestamp.
